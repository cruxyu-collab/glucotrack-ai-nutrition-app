## 2. 起動手順
- プロジェクトディレクトリへ移動:
  cd C:\workspace\02_glucotrack-ai-nutrition-app
- 開発サーバー起動:
  npx expo start
- iPhone 16e の「Expo Go」アプリよりプロジェクトを選択して即時起動。

---

## 3. 主要実装機能サマリー
1. **画像解析パイプライン (Vision AI)**: 800px最適化処理により、食品表示ラベル(OCR)および料理写真から実測平均2〜4秒で9大栄養素を自動解析。
2. **料理名即時推計 (Text AI)**: 料理名テキスト入力から画像転送なしに約1〜2秒で1人前の栄養素を自動推計。
3. **臨床バリデーション防壁**: 非食品保存遮断、糖質>炭水化物矛盾検知、高糖質(30g超)警告、栄養素ゼロ保存遮断。
4. **ローカル3x3グリッド集計**: 臨床重要度順に統一された3x3グリッドで摂取実績を自動合算。
5. **ドットカレンダー＆日付ナビゲーション**: ミニマルドット(緑/黄)による月間実績確認と過去日の閲覧。
6. **日韓バイリンガル**: ⚙️設定アイコンから日本語／韓国語を即時切替可能。
